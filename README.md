# NLP_Project
A machine learning and NLP project that classifies news articles into categories such as Business, Entertainment, Politics, Sport, and Technology using text pre-processing, TF-IDF vectorization, and a Multinomial Naive Bayes classifier.
# 📰 NLP News Reader Pro

An end-to-end Natural Language Processing (NLP) project that classifies news articles into predefined categories using Machine Learning. The project performs text preprocessing, TF-IDF feature extraction, trains multiple classification models, and predicts the category of unseen news articles through an interactive web interface.

## 🌐 Live Demo

https://news-reader-pro.lovable.app

## 🚀 Features

- Classifies news articles into multiple categories
- Automated text preprocessing and cleaning
- TF-IDF feature extraction
- Compares multiple machine learning algorithms
- Automatically selects the best-performing model
- Predicts categories for new, unseen news articles
- Simple and responsive frontend built with Lovable AI

## ⚙️ Machine Learning Pipeline

1. Load BBC News Dataset
2. Data Cleaning & Text Preprocessing
3. Stopword Removal & Lemmatization
4. TF-IDF Feature Extraction
5. Train Multiple Machine Learning Models
6. Compare Model Performance
7. Save the Best Model
8. Predict Categories for New Articles
